# 🎙️ STT_OFFLINE — Преврати речь в текст, без облаков

**Полностью оффлайн. Полностью под твоим контролем.**

Преобразователь речи в текст, который работает прямо на твоём компьютере. Не отправляет
твои разговоры в облака, не требует подписки и запускается даже на слабых машинах.
Просто скачай, запусти — и говори.

## Что внутри

- **Два мощных STT-движка**: Whisper (очень точный, но требует видеокарту NVIDIA с CUDA для быстрой работы) и Vosk (
  мгновенный, работает даже на слабом железе, но чуть менее точный).
- **REST API** — встраивай распознавание речи в свои проекты на Python, Go, JavaScript, C# — на любом языке.
- **Интерактивный терминал** — меняй движки на лету, смотри результат распознавания в реальном времени. Всё в одном
  окне.
- **Готовый .exe** — для тех, кто не пишет код. Запустил и работает.
- **Кроссплатформа** — Windows, Linux. Везде одинаково.
- **Простота расширения движков** - легко включать отключать движки распознавания речи в `app/stt/__init__.py`

## 🎯 Для кого

- **Разработчики** — встраивай STT в свои проекты через REST API.
- **Создатели голосовых ассистентов** — распознавание речи без облаков и задержек.
- **Энтузиасты умного дома** — голосовой интерфейс без интернета.
- **Просто пользователи** — говоришь в микрофон, а компьютер печатает твою речь.

### ⚙️ Системные требования

**Для Windows:**
Необходим пакет **Microsoft Visual C++ Redistributable**. Скачать можно
с [официального сайта Microsoft](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170).

**Для Linux:**
Может потребоваться установка аудио-библиотек:

```bash
sudo apt install libportaudio2 portaudio19-dev libasound-dev -y
```

### ⚡Быстрый старт для разработчиков

1. Создать виртуальное окружение (обязательно иначе засорится глобальный Python).
2. Инициализировать проект: `python start.py` (создадутся каталоги для речевых моделей).
3. Скачать модели распознавания речи:
    - [whisper](https://huggingface.co/models?sort=downloads&search=whisper)
    - [vosk](https://alphacephei.com/vosk/models)
      **Чуть позже будет добавлена автоматическая закачка для whisper/vosk**
4. Положить модели в каталог, модели `whisper` в `resources/models/whisper`, `vosk` в `resources/models/vosk`.
5. Проверить, что всё работает, запустить приложение в интерактивном режиме: `python cli.py run`, появится чат с моделью
   введите `@info` и выберите одну из моделей в формате `@start <engine> <model>`, движок запущен говорите.
6. Подробная справка о работе с приложением `python cli.py`, покажет все доступные команды.
7. Сборка приложения в исполняемый файл `python builder.py` (гарантированно работает на текущей версии, если код не был
   модифицирован).

### 🔁Работа с сервером

1. Подъём сервера в терминале введите: `python cli.py run-server -p 8000` (проследите чтобы порт 8000 был свободен, или
   укажите другой, в этом примере 8000). Далее вся работа строится через http.
2. Посмотреть docs и дергать api ручки можно из: [http://localhost:8000/docs/](http://localhost:8000/docs/)
3. Посмотреть доступные модели и голоса [http://localhost:8000/tts/info/](http://localhost:8000/tts/info/)
4. Запуск приложения (движка распознавания речи), в engine укажите доступный движок например `vosk`:
    -
    vosk: [http://localhost:8000/start/?engine=vosk&model=vosk-model-small-ru-0.22](http://localhost:8000/start/?engine=vosk&model=vosk-model-small-ru-0.22)
    -
    whisper : [http://localhost:8000/start/?engine=whisper&model=medium](http://localhost:8000/start/?engine=whisper&model=medium)
5. Снять распознанный из речи текст можно здесь: [http://localhost:8000/messages/](http://localhost:8000/messages/) -
   возвращает все сообщения сигналы приложения, в том числе result с текстом (можно делать поллинг из других
   приложений).
6. Остановка приложения (движка распознавания речи): [http://localhost:8000/stop/](http://localhost:8000/stop/)
7. Остановка сервера [http://localhost:8000/shutdown/](http://localhost:8000/shutdown/)

## 💿Релиз

Для запуска приложения без исходного кода, предусмотрен бинарный .exe файл [Скачать последнюю версию для windows](https://github.com/Mike2024New/STT_OFFLINE/releases/latest) , для
linux можно создать бинарный файл самостоятельно из исходного кода командой python builder.py.

### Работа с бинарником:

Скачай файл распакуй перейди в эту директорию из cmd и выполни:

Скачай ZIP-архив из релиза и распакуй его в любую папку
Открой командную строку (cmd) в этой папке
Посмотреть доступные команды stt (для бинарника linux ./stt).
Запустить приложение в интерактивном режиме stt run (для бинартника linux ./stt run).
Поднять сервер stt run-server -p 8000 (для бинарника linux ./stt run-server -p 8000), ** проверить что порт 8000
свободный или выбрать другой. **.
